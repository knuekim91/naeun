올해 · 9월 / 2027학년도 (최신)

"핵심적·기본적 내용 출제" 기조를 유지하면서도 자료 해석·탐구 사고력을 평가하는 문항 비중이 강조됨. 표 분석형 문항은 계속 20번 부근에 배치되는 흐름이 이어지고 있습니다.

종합 시사점 — 표 분석 문항은 4단원(계층·불평등)·5단원(인구·사회 변동)에서 집중 출제되며 거의 매회 20번 부근에 배치됩니다. 난이도의 축이 복잡한 계산에서 함정 선지(비율 vs 실수, 모집단 혼동)로 옮겨가는 중이므로, 계산이 쉬워 보여도 끝까지 검산하는 습관이 중요합니다.

② 표 분석 8단계 전략

  1. 표의 뼈대부터 읽는다. 행/열의 의미, 단위(%/명)를 먼저 확인한다.
  2. 전체를 100(또는 기준 인원)으로 놓고 표를 직접 채운다. 비율은 반드시 실수로 환산해서 적는다.
  3. 조건은 풀 수 있는 순서대로 정리한다. 조건 하나로 미지수 하나씩 연쇄적으로 제거한다.
  4. 가로 합·세로 합을 항상 검산한다.
  5. 이동표는 '이동 전(부모)'과 '이동 후(자녀)'를 구분한다. 대각선=대물림, 그 외=이동.
  6. 부양비는 '생산가능인구 고정' 풀이를 쓴다. 유소년·노년·총부양비, 노령화지수를 즉시 상호 환산한다.
  7. 함정 선지 체크리스트
    • · 분모가 다른 비율끼리 더하거나 빼지 않았는가
    • · '전체' 대비 비율인지 '특정 집단 내' 비율인지 구분했는가
    • · 비율이 같아도 모집단이 다르면 실수는 달라질 수 있음을 반영했는가
    • · 표에 없는 항목(외국인, 무응답 등)의 존재 가능성을 배제하지 않았는가
  8. 선지를 먼저 훑어 '실수 비교'인지 '비율 비교'인지 파악한 뒤 표를 채운다.

  1. 실수 환산: t년 상층 100만/중층 300만/하층 600만. t+10년 상층 400만/중층 1,000만/하층 600만.
  2. ㄱ: 10%<30%<60%로 아래로 갈수록 커지는 피라미드형 → 참.
  3. ㄴ: t+10년은 중층(50%)이 가장 커 다이아몬드형 → 참.
  4. ㄷ: 하층 실수는 600만 명으로 동일 → 참. (비율은 60%→30%로 줄었지만 실수는 그대로인 함정)
  5. ㄹ: 중층 실수는 300만→1,000만으로 약 3.33배이지 4배가 아님 → 거짓.
A2
정답 ① (ㄱ,ㄴ,ㄹ)
  1. 을국: 상층 40만 명=10% → 전체 인구 400만 명. 중층 80만, 하층 280만.
  2. 갑국: 상층 100만, 중층 150만, 하층 250만.
  3. ㄱ: 250만 < 280만 → 참. ㄴ: 100만−40만=60만 → 참.
  4. ㄷ: 150만÷80만=1.875배로 2배 미만 → 거짓.
  5. ㄹ: 을국은 상(10%)<중(20%)<하(70%)로 피라미드형 → 참.
A3
정답 ① (ㄱ,ㄴ)
  1. t+1년 인구=1,000만×1.2=1,200만. t년 상층=100만 → t+1년 상층=150만 → A=150÷1,200×100=12.5 → ㄱ 참.
  2. 검산: 12.5+37.5+50=100.
  3. 중층: t년 400만, t+1년 450만 → 50만 명 많음 → ㄴ 참.
  4. 하층: t년 500만, t+1년 600만 → 다름 → ㄷ 거짓(비율 50%로 같지만 실수는 증가).
  5. 두 시점 모두 상<중<하인 피라미드형으로 유형 변화 없음 → ㄹ 거짓.
B1
정답 ①
  1. 하강 이동=상→중(6)+상→하(4)+중→하(30)=40명 → ① 참.
  2. 전체 이동=상승(30)+하강(40)=70명=35% → ② 거짓.
  3. 부모 구성(10/50/40%)과 자녀 구성(10/43/47%)이 달라 → ③ 거짓.
  4. 하층 부모 80명 중 이동 20명=25%로 절반 미만 → ④ 거짓.
  5. 중층 부모 100명 중 대물림 60명=60%로 50%가 아님 → ⑤ 거짓.
B2
정답 ③ (ㄱ,ㄴ,ㄷ)
  1. 상층 부모 6%=60명 → 전체=1,000명 (ㄱ 참). 이후 %×10=실수.
  2. 대물림=3+40+20=63%=630명 (ㄴ 참).
  3. 상승=5+0+14=19%=190명, 하강=2+1+15=18%=180명 → 190>180 (ㄷ 참).
  4. 자녀 상층 비율(열 합)=8%로 부모(6%)보다 높음 → ㄹ("낮다")은 거짓.
B3
정답 ② (A=40, B=10 / ㄱ,ㄹ)
  1. A(상층 행)=80−30−10=40. B(중층 열)=360−30−320=10.
  2. ㄱ: A(40)는 B(10)의 4배 → 참.
  3. ㄴ: 상승=20+60+10=90명, 하강=30+10+60=100명 → 90<100이므로 거짓.
  4. ㄷ: 대물림=40+320+250=610명=76.25%로 75%가 아님 → 거짓.
  5. ㄹ: 부모 상층 10%, 자녀 상층(열 합) 120/800=15% → 참.
C1
정답 ② (ㄱ,ㄴ,ㄷ)
  1. 노령화지수: t년 100, t+20년 300 → 정확히 3배 (ㄱ 참).
  2. 총부양비: t년≈66.7%, t+20년≈57.1% → t년이 높음 (ㄴ 참).
  3. 고령 인구 200만→300만으로 100만 명 증가 (ㄷ 참).
  4. 유소년부양비: t년≈33.3%, t+20년≈14.3%로 오히려 낮아짐 → ㄹ 거짓.
C2

  4. 고령 인구 120만<150만 (ㄷ 참). 총인구 1,120만>750만 (ㄹ 참).
C3
정답 ③ (ㄱ,ㄴ,ㄹ)
